# Checklist Berkas Pendaftaran CPNS

Centang `[x]` kalau sudah siap. **Selalu cocokkan dengan syarat formasi di pengumuman resmi** — tiap instansi bisa meminta berkas tambahan atau format berbeda. Daftar ini adalah panduan umum, bukan syarat resmi.

## Berkas umum

- [ ] Pas foto terbaru berlatar merah (sesuai ketentuan pengumuman)
- [ ] KTP / surat keterangan pengganti KTP
- [ ] Ijazah asli (scan berwarna, terbaca jelas)
- [ ] Transkrip nilai asli
- [ ] Surat lamaran (ditujukan ke instansi sesuai format pengumuman)
- [ ] Surat pernyataan (bermaterai, sesuai format pengumuman)
- [ ] Daftar riwayat hidup / CV

## Berkas khusus (hanya kalau diminta formasi)

- [ ] Sertifikat akreditasi program studi / perguruan tinggi
- [ ] Sertifikat TOEFL / kemampuan bahasa Inggris
- [ ] Sertifikat komputer / keahlian lain
- [ ] Surat keterangan pengalaman kerja
- [ ] Surat keterangan sehat
- [ ] Surat keterangan bebas narkoba
- [ ] Surat keterangan catatan kepolisian (SKCK)
- [ ] Surat keterangan tidak pernah diberhentikan dengan tidak hormat
- [ ] Dokumen lain sesuai syarat formasi: [tulis di sini]

## Sebelum unggah

- [ ] Semua scan terbaca jelas, tidak terpotong, tidak buram
- [ ] Format file sesuai ketentuan (umumnya PDF/JPG, perhatikan batas ukuran file)
- [ ] Nama file jelas (contoh: `ijazah-nama.pdf`)
- [ ] Data di berkas sama dengan data di akun SSCASN (nama, tanggal lahir, nomor ijazah)
- [ ] Sudah membaca ulang seluruh syarat formasi di pengumuman resmi
